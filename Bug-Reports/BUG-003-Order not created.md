Title

Order not created after successful payment

Severity

High

Priority

High

Module

Checkout / Payment

Environment

Production

Preconditions
User logged in
Product added to cart
Steps to Reproduce
Add a product to cart.
Proceed to checkout.
Complete payment successfully.
Return to Kalakriti website.
Check Orders page.
Expected Result
Order should be created successfully.
Payment status should be updated.
Order should appear in "My Orders".
Actual Result
Payment completed successfully.
Order was not created.
Payment information was not reflected on the website.
User could not see the order in the application.
Impact
User may lose trust in the platform.
Payment may be collected without order confirmation.
Revenue and order tracking inconsistencies may occur.
Severity Justification

High because it affects the core e-commerce purchase flow.

Status

Open
