# Kalakriti Test Plan

## 1. Project Overview

Kalakriti is an e-commerce platform that allows users to browse products, search products, manage carts, place orders, and manage profiles.

## 2. Objective

To verify that all functionalities of the Kalakriti website work as expected and provide a seamless user experience.

## 3. Scope of Testing

### In Scope

- User Registration
- User Login
- Product Listing
- Product Details
- Search Functionality
- Cart Management
- Checkout Process
- User Profile
- Orders

### Out of Scope

- Third-party payment gateway internal processing
- Browser compatibility beyond major browsers

## 4. Testing Types

### Manual Testing

- Functional Testing
- UI Testing
- Validation Testing

### Automation Testing

- Playwright

### API Testing

- Postman

### Performance Testing

- JMeter

### Security Testing

- OWASP ZAP

## 5. Test Environment

### Browser

- Chrome
- Edge

### Device

- Laptop/Desktop

### Environment

- Production

## 6. Entry Criteria

- Website deployed successfully
- Features available for testing

## 7. Exit Criteria

- Critical bugs fixed
- Test cases executed
- Test summary report generated

## 8. Deliverables

- Test Plan
- Test Cases
- Bug Reports
- Automation Scripts
- API Collections
- Performance Reports
- Security Reports

## 9. Risks

- Environment downtime
- API unavailability
- Third-party service issues
